# Attribution

This file records upstream license notices for skills imported from
external projects. It is regenerated by
`scripts/import_hermes.py --apply` for every upstream import.

Each skill's `source.license_notice_path` field in `skills-index.json`
points to the section here that satisfies its license requirements.
