# Fonts

Shipped so compositions render the same on every machine with no network
(HyperFrames lint wants every named font as a local `@font-face`).

| File | Family | Role in the kit | Licence |
|---|---|---|---|
| Anton-Regular.ttf | Anton | `hero` tier: condensed slab for the big words | SIL OFL 1.1 |
| ArchivoBlack-Regular.ttf | Archivo Black | `hero` tier, wider alternative | SIL OFL 1.1 |
| InstrumentSerif-Regular.ttf, InstrumentSerif-Italic.ttf | Instrument Serif | `mid` tier: editorial serif, italic asides | SIL OFL 1.1 |
| DMSans-Variable.ttf | DM Sans | `sub` tier: subtitle chip, cards | SIL OFL 1.1 |
| SpaceMono-Regular.ttf, SpaceMono-Bold.ttf | Space Mono | `mono` tier: counters, stamps, terminal text | SIL OFL 1.1 |
| PermanentMarker-Regular.ttf | Permanent Marker | `hand` tier: marker lettering, sound effects | Apache 2.0 |

All come from github.com/google/fonts. OFL.txt is the SIL Open Font License
text; each OFL font may be redistributed with the software that uses it.
