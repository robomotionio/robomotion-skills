# Robomotion Skills

The skill library for Robomotion's AI agents: the **Hermes Agent**, the **Google ADK Agent** and the **DeepSeek Agent**. A skill is a folder with a `SKILL.md` that teaches the agent how to do one kind of task, sometimes with scripts it can run. Skills come in packs: all but one are taken from popular open-source Agent Skills repositories, and `designer-skills` is our own.

Every pack is hand-picked. Agents run skills in a sandbox, but a skill is still instructions an agent follows and scripts it runs next to a customer's credentials, so a pack gets in only when it is popular, its licence lets us redistribute it, it is useful inside the sandbox, and a person has read it. Each pack is pinned to an upstream commit, and any command-line tool it needs is installed at a pinned version when the agent's image is built. [DEVELOPMENT.md](DEVELOPMENT.md#popular-but-not-here) lists the popular repositories that are not here, and why.

Pick the skills an agent needs in the Agent Editor of a flow in the Designer; the agent loads them when it runs.
