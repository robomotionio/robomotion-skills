# Brand identity

When work is *for a brand*, consistency beats novelty. Pull the brand's rules
first (ask for or read a brand guide / existing assets) and design within them.

## Logo types

- **Wordmark** — styled company name (Google, Coca-Cola).
- **Lettermark / monogram** — initials (IBM, HBO).
- **Pictorial mark** — a recognizable icon (Apple, Twitter bird).
- **Abstract mark** — a non-literal symbol (Nike swoosh).
- **Combination mark** — symbol + wordmark (most safe default; works locked-up or
  split).
- **Emblem** — text inside a shape/badge (Starbucks); strong but less flexible at
  small sizes.

Logo qualities: legible at favicon size, works in one color, simple enough to
recall, and distinct in its category. (You generate *concepts/explorations* with
the image toolkit; final logos are usually refined as vectors.)

## Identity system (what "the brand" actually is)

- **Color** — primary, secondary, neutrals, with exact values and usage rules.
- **Type** — a display/heading face and a body face, with a scale.
- **Logo + clear-space + minimum size + don'ts.**
- **Imagery style** — illustration vs photography, treatment, subject matter,
  the *consistent rendering* that makes a set recognizable.
- **Iconography & graphic elements** — line weight, corner radius, motifs.
- **Voice → visual** — translate adjectives into choices: "friendly" → rounded
  geometric sans, warm palette, soft shapes; "authoritative" → serif, restrained
  palette, generous whitespace; "technical" → mono accents, grid-forward,
  high-contrast.

## Staying on-brand with AI images

- Lock the **palette** (exact hexes) and a **named illustration style** up front,
  then reuse the same style language in every prompt.
- Establish one approved "look" image, then drive the whole set with the
  reference-image workflow (see `references/image-prompting.md`) so rendering,
  palette and mood stay identical.
- Keep brand motifs (a shape language, a recurring background element) consistent
  across pieces.
- Don't reproduce other companies' trademarked logos/characters.

## Consistency checklist

Same palette roles? Same type system? Same imagery rendering across the set? Same
spacing/margins? Logo clear-space respected? If a piece breaks one of these, it
will read as off-brand even if it's individually attractive.
