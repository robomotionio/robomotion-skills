# Changelog — designer-skills

All notable changes to the Robomotion-authored `designer-skills/` group.
The format roughly follows [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] — 2026-06-01
- Initial release. New `graphic-design` skill: A-Z graphic-design knowledge for
  AI image generation — composition & layout, color theory, typography, brand
  identity, format/aspect specs, a design-critique rubric, and model-aware
  prompt craft for the OpenAI (gpt-image) and Gemini (Nano Banana) image
  toolkits. Pure knowledge — no scripts, no env, no API keys (rendering is done
  by the image toolkits wired into the agent).
